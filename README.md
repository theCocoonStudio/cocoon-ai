# cocoon-ai

Component and utility library for the Cocoon studio site — a dual-engine React 19 / react-three-fiber app.

Built with Vite in library mode. `react`, `react-dom`, `three` and `@react-three/fiber` are peer dependencies and are never bundled.

```bash
npm run build      # emit dist/index.js
npm run dev        # rebuild on change
```
