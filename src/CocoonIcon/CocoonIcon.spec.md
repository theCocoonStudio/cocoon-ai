# CocoonIcon spec

Retroactive: written 2026-09-06 from the component in `cocoon-ai-records/temp/React Components/CocoonIcon` (Opus, 2026-08-29/31) and its verification notes. Where a line changes what the old component did, it says so.

## meta

meta.target: portable
meta.runtime: client
meta.file: src/CocoonIcon/index.jsx

## imports

imports.1: import { cloneElement, isValidElement } from 'react'
imports.2: import { icons, iconNames } from './icons.js'

## props

props.1: name — one of iconNames, optional; omitted when slots.1 is given
props.2: size — number (px) or CSS length string, optional, default '1em' so the icon is the font size (was number only; a string produced a broken value and fell back to 1em silently. Izzy, 2026-08-30: strings are to be accepted)
props.3: color — CSS colour string, optional, default inherit; the text colour
props.4: title — string, optional; the accessible name. Omitted, the icon is decorative
props.5: style — object, optional, merged last onto the wrapper
props.passthrough: yes → spread onto the root <span>
props.ref: accepted → root DOM node

## slots

slots.mechanism: children
slots.1: children — one inline <svg> element, used when props.1 is absent; sized to fill the box (markup.3)

## context

context.consumed: none
context.provided: none

## state

state: none
state.reset: none

## markup

markup.1: root <span> display inline-flex, width and height props.2, flex none, line-height 1, vertical-align -0.125em, color props.3 when given, then props.5, then passthrough
markup.2: with props.1: the named icon's <svg>, width and height 100%, display block; the artwork fills the box exactly because the square files carry no margin and every fill is currentColor
markup.3: with slots.1: the child cloned with the same width, height and display, its own style merged after
markup.4: props.4 absent: root carries aria-hidden="true"; present: root carries role="img" and aria-label props.4, no aria-hidden

## exits

exits.throws: from render when props.1 names no icon (message lists iconNames), or when neither props.1 nor slots.1 is given; the lookup is Object.hasOwn so constructor, toString, valueOf and **proto** throw like any other missing name. Owner: the nearest error boundary
exits.suspends: never
exits.handler-failures: none

## library

library.export: named `CocoonIcon` from src/index.js; `icons` and `iconNames` named from the same entry
library.side-effects: none
library.utils: src/CocoonIcon/icons.js — generated by assets/icons/build.js from the 13 `icon-*-square.svg` files as path data rendered with createElement, no SVG loader needed by any consumer (was `./x.svg?react` imports needing vite-plugin-svgr, with the SVGs copied by a Python script that could go stale); a test asserts the generated module matches the files
library.docs: docs/CocoonIcon.md — props, the two defaults and why the files make them work, adding an icon
